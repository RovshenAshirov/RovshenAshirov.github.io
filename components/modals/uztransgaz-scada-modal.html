UzTransGaz SCADA - SCADA Monitoring Tizimi

Maqsad

Davlat loyihasi - gaz tarmoqlarini real-time monitoring qilish va boshqarish tizimi. SCADA (Supervisory Control And Data Acquisition) asosida ma'lumotlarni yig'ish va tahlil qilish.

Mening Rollim

  • Microservice arxitektura asosida backend servislarni ishlab chiqish
  • Real-time monitoring va vizualizatsiya tizimlari yaratish
  • Celery va cron task'lar orqali fon jarayonlarni avtomatlash
  • Chart va diagrammalar orqali monitoring ma'lumotlarini vizualizatsiya
  • MinIO service integratsiyasi orqali fayllarni boshqarish
  • Vault yordamida maxfiy konfiguratsiyalarni xavfsiz boshqarish
  • Redis orqali kesh va ishlash tezligini oshirish
  • Loyihaning core module ishlab chiqishda ishtirok etish

Texnologiyalar

Django DRF Celery MinIO Vault Redis PostgreSQL
